# 光伏组串IV扫描台

扫描员提交组串开路电压、短路电流与填充因子。写入后走 PostgreSQL 通知通道叫醒独立工人，工人不轮询空转。填充因子不低于 0.72 为合格，否则衰减。页面是 Vue 3。

## 贴码规矩

- 进站后顶栏并排四钮：总览、交扫、贴码口、退出。
- 贴码口专页铺满整页，分待贴清单、已贴清单、退回原因三格；空着也写「还没有贴码痕迹」，码号不进总览末列，只在单据详情里看。
- 组串没贴现场二维码就禁止入队，退回原因写「还没贴现场码」。
- 贴码和入队同一次写入（同一事务一次提交），不拆两笔。
- 同一块码被两人抢登时只准一份成功，后到的立刻收到「该码已被占用」。
- 观察员（watcher）能翻牌册和单据上的码，不能改贴也不能报送。

## 技术栈

- 后端：Litestar、Uvicorn、psycopg 同步写入
- 工人：`LISTEN/NOTIFY` 唤醒后认领
- 前端：Vue 3、Vite、nginx 反代 `/api`

## 接口

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/auth/login` | 登录拿 token |
| GET | `/api/logs` | 扫描单列表（含码号快照） |
| POST | `/api/logs` | 交扫；未贴码退回 `还没贴现场码` |
| GET | `/api/codes/board` | 待贴清单 / 已贴清单 / 退回原因 |
| POST | `/api/codes/paste` | 贴码入队；重码 `409 该码已被占用` |
